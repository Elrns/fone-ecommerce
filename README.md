## 🛠️ Tecnologias Utilizadas

O projeto foi construído puramente com tecnologias web fundamentais para garantir leveza e controle total sobre o design:

- **HTML5:** Estruturação semântica de todas as páginas.
- **CSS3:** Estilização avançada, incluindo:
  - Flexbox e Grid Layout (Bento Grid).
  - Variáveis CSS para fácil manutenção de cores.
  - Efeitos de desfoque (`backdrop-filter`) e Glassmorphism.
  - Responsividade total para dispositivos móveis (Mobile-First).
- **JavaScript (Vanilla):** Lógica de navegação, menu mobile e interatividade do checkout.
- **ScrollReveal JS:** Para animações de entrada ao rolar a página.
- **Boxicons:** Biblioteca de ícones vetoriais.

---

## ✨ Funcionalidades

- [x] **Home Dinâmica:** Apresentação de impacto com destaque para o produto principal.
- [x] **Página de Especificações:** Layout em Bento Grid organizando detalhes técnicos de forma visual.
- [x] **Página de Detalhes:** "Copy" de vendas focado em conversão e benefícios.
- [x] **Sistema de Avaliações:** Grid responsivo com feedbacks de clientes e prova social.
- [x] **Checkout Simulado:** Formulário completo com validação de campos e troca de métodos de pagamento (PIX, Boleto, Cartão).
- [x] **Página de Contato:** Inclui formulário funcional e integração visual com Google Maps em modo Dark.

---

## 📱 Responsividade

O projeto foi rigorosamente testado em diferentes resoluções e navegadores (incluindo Safari/iOS), garantindo que:
- O menu lateral (gaveta) funcione fluidamente em iPhones.
- Fontes de inputs não causem zoom automático indesejado no mobile.
- O layout se adapte de telas ultra-wide até smartphones pequenos.

## 🚀 Como rodar o projeto localmente

1. Clone o repositório:
 ```bash
   git clone [https://github.com/Elrns/fone-ecommerce.git](https://github.com/Elrns/fone-ecommerce.git)
 ```

2. Entre na pasta do projeto:
   
``Bash
cd fone-ecommerce``

3. Abra o arquivo index.html no seu navegador de preferência.
